# Agent instructions

This is a Naf project: a TypeScript REST API with Fastify, MongoDB and Swagger.

- Create models, CRUD routes, controllers and request schemas with the `naf` CLI, not by hand. Read `.claude/skills/naf/SKILL.md` first, it lists the commands, the field syntax and how to add custom actions.
- Check your changes with the `test` script of the project's package manager, e.g. `npm test`. It runs the type check.
- `npm start` runs the server on port 2101 in watch mode and does not exit, start it in the background.
